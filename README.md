# Radar de Oportunidades

MVP responsivo para pequenos fornecedores encontrarem oportunidades de compras públicas.

## Estado atual
- Dashboard
- Busca
- Filtro por UF e categoria
- Favoritos persistidos no navegador
- Alertas locais
- Dados de demonstração identificados
- Layout responsivo

> Os dados atuais são de demonstração. A próxima etapa é conectar fontes públicas reais mantendo a interface desacoplada.

## Rodar
```bash
npm install
npm run dev
```

## Testes
```bash
npm test
```

## Build
```bash
npm run build
```
